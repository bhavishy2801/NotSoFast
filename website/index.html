A few useful details.

Does the website run checks on my repository?

No. This site introduces the product. The desktop and local browser app run the Git/SQLite evidence engine on your machine.

Will publication edit or push my source repository?

No. Guarded publication writes to the application's managed branch. You can export the result. Your source working tree and GitHub remote remain unchanged.

Do I need an AI subscription?

No. Evidence tools work without a model. The optional Model lab accepts an existing local server or a compatible provider that you configure.

What does cloud saving include?

Explicit portable saves contain your preferences, draft and GitHub bookmarks. They require your own configured Supabase project. Git data, evidence and model keys are excluded.

What does the evidence actually prove?

Exact scoped claims over tracked immutable Git snapshots, under the documented trust assumptions. It does not infer semantic equivalence or guarantee general agent safety.

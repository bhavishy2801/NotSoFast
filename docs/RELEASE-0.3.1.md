# NotSoFast 0.3.1

- Fix theme clipping with padded scrolling content and reachable actions.
- Keep Theme and Account accessible on narrow screens.
- Improve dialog wrapping and mobile controls.
- Add offline profile backup/import with preview-before-restore, bookmark removal and theme reset preview.
- Add a Vercel-ready product website with screenshot tour, coverage example and release links.
